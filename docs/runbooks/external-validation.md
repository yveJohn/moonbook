# 外部依赖生产验收清单

这些验收需要真实账号、商业授权、网络白名单或生产变更权限，不由本地自动化代替。每项必须在发布工单记录责任人、受控输入、执行入口、通过标准、风险和仓库外证据位置；不得把凭据、Cookie、邮件正文或客户数据提交到 Git。

| 外部项 | 责任人 | 受控输入与入口 | 通过标准 | 主要风险 | 证据位置 |
| --- | --- | --- | --- | --- | --- |
| EPUSDT 支付 | 支付负责人 | 测试金额、真实回调域名；按 `epusdt-callback.md` 创建订单并观察回调 | 签名验证、幂等回调、订单/流水/权益一致，维护 503 后可重投 | 重复入账、漏单、凭据泄露 | 支付平台流水号、脱敏请求 ID、财务核对报告 |
| AI 供应商 | AI 负责人 | Secret 管理器中的 API Key；管理端模型探测和最小生成请求 | 配额、超时、错误映射和审计正常，数据库只保存环境变量引用 | 成本、敏感提示泄露、供应商限流 | 供应商请求 ID、脱敏响应摘要、费用截图 |
| 论坛与采集代理 | 内容负责人 | 仓库外 Cookie、代理白名单；受控单源采集任务 | 登录态有效、限速遵守、内容和失败重试可追踪 | 封禁、条款违规、Cookie 泄露 | 任务 ID、来源授权、脱敏日志 |
| SMTP | 运维负责人 | 专用测试收件人和 Secret；发送一次验证码/通知 | SPF/DKIM/DMARC、投递、退信和限速符合预期 | 垃圾邮件、地址泄露、配额耗尽 | 邮件服务 message ID、投递记录 |
| GVA 商业授权 | 法务/产品负责人 | 合同、插件清单、目标域名/主体 | 使用范围和分发方式经书面确认 | 许可证不合规 | 合同系统编号，不复制合同到仓库 |
| TLS 与可信代理 | 运维负责人 | 正式域名、证书、受控 TLS 代理和来源 IP | TLS 1.2+、证书链/HSTS 合格；伪造 `X-Forwarded-*` 不影响应用客户端 IP | 头伪造、错误协议判断、证书过期 | SSL 扫描、代理配置审计、请求 ID |
| DNS/流量切换 | 变更负责人 | 已批准记录、TTL、内部验证入口 | 内外探测、回源、回退入口和监控全部正常 | 缓存传播、误切生产 | DNS 变更记录、探测时间线 |

任何一项未指定责任人、未获授权、缺少通过标准或证据位置均为 No-Go。真实支付、SMTP、AI 调用和生产切流会产生外部状态，必须在对应工单获批后单独执行。
