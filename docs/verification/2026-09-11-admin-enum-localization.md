# 管理后台枚举中文显示复查

## 范围与实现

扫描管理前端全部 Vue 表格及相关详情，按字段核对既有中文选项、Go 枚举、数据库约束及只读旧系统常量。17 个页面或组件补齐显示：

- 钱包：奖励阶段、收支方向、币种、业务（含历史免广告购买及奖励币过期）。
- 商品、订单：商品类型、订单类型，兼容旧系统 `buy_*` 类型。
- 平台任务：模块、任务类型及详情。
- 采集、内容生产：抓取阶段、导入模式、合并策略、清洗内容类型、合并正文来源。
- 作者、分类：本系统与各类旧系统迁移来源。
- 充值设置：舍入方式。
- MCP、CLI、菜单、代码生成与导出模板：参数类型、请求位置、索引类型及查询运算选项。

`adminEnums.js` 只在展示层按字段映射，未知值原样保留，空值显示 `-`。列表和详情共享映射，不改 API 请求、原始数据、业务判断或 Long ID。来源名称、数据库表名、字典标识、字符编码等技术或自定义内容保留；错误来源由后端写入中文，本次无需改动。既有省略号、悬浮完整展示和复制由表格指令继续处理。

- `corepack pnpm@10.15.1 run test:moonbook`：45 个用例通过，覆盖字段语义差异、历史枚举、未知值、空值、原型属性、长 ID 及不改变数据。
- `corepack pnpm@10.15.1 run lint`：通过。
- `corepack pnpm@10.15.1 run build`：通过；第三方 arcdash 的 BigInt 构建警告仍存在。
- `corepack pnpm@10.15.1 run check:supply-chain`：通过。
- 使用 Vue 模板 AST 复扫枚举列，逐项检查残留无 formatter 的列：对应中文选择器、已中文字段或需保留的技术/自定义标识。
- 本轮未进行真实浏览器回归，也未部署生产环境。

## 服务影响

仅影响管理前端 Web。部署时重建并更新 Web 服务；后端 Server、Reader、数据库、Redis、MinIO 无需重启或迁移。
